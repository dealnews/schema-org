# Vocabulary snapshot

`schemaorg-current-https.jsonld` is a snapshot of
https://schema.org/version/latest/schemaorg-current-https.jsonld, downloaded
2026-07-10. It's checked in so `bin/generate.php` produces reproducible
output without needing network access. To pick up a new Schema.org release,
re-download that URL to this path and re-run `composer generate`.
